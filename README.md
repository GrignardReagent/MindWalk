# MindWalk

中文 | [English](README.en.md)

边走边说，字实时出现在屏幕上的框里，再自动整理成思维导图。默认通过爱丁堡大学的 ELM 调用模型，也兼容其他 OpenAI 格式的接口。

## 部署到网页（推荐）

用 [Render](https://render.com) 免费部署，自带 HTTPS，手机直接打开网址就能用，不用开电脑。

1. 登录 Render，连接 GitHub。
2. Dashboard → **New → Blueprint** → 选这个仓库。它会读取 `render.yaml`。
3. 填 `OPENAI_API_KEY`（ELM 的 key），点 **Apply**。
4. 部署完成后，在服务的 **Environment** 页复制 `ACCESS_KEY`。这就是访问密钥，也可以改成你自己的（至少 16 个字符）。
5. 手机打开 `https://<你的服务名>.onrender.com`，输入密钥。手机会记住它，只需输入一次。

省事的办法：把 `https://<你的服务名>.onrender.com/#key=<密钥>` 发给自己，点开就自动解锁。`#` 后面的内容不会发到服务器，也不会出现在日志里。

没有密钥的人只能看到输入密钥的页面，用不了你的 API 额度。免费版 15 分钟没人用会休眠，再打开要等约 1 分钟。

## 本地运行

```bash
npm install
cp .env.example .env   # 填 OPENAI_API_KEY 和 ACCESS_KEY
```

```bash
set -a; . ./.env; set +a
npm start
```

手机浏览器只在 HTTPS 下开放麦克风，本地运行时还需要隧道，例如 cloudflared（`bash scripts/setup.sh` 会下载到 `bin/` 并校验 SHA-256）：

```bash
bin/cloudflared tunnel --url http://localhost:8787
```

## 实时出字

点“开始录音”后，每句话说完稍停一下（约 0.6 秒），1 到 3 秒内这句话就出现在框里。原理：录音在停顿处切成 4 到 25 秒的小段，每段一录完就转写。小段之间有重叠，不会切断字。

想法每 2 分钟左右整理一次进导图，结束录音时再整理剩下的，这样模型能看到完整的思路。

## 识别准确度

已经做了的：

- **转写模型**：默认用 OpenAI 最新的 `gpt-transcribe`。接口（比如 ELM）没有它时，自动依次改用 `gpt-4o-transcribe`、`whisper-1`，服务器日志里会提示一次。
- **指定语言**：底部“识别：中文 / English / 中英混合”。说话夹英文单词就选“中英混合”。中文会输出简体和标点。
- **上下文和关键词**：每段转写都带上前一句，导图里已有的词和 `TRANSCRIBE_VOCAB` 作为关键词一起发送，专有名词前后写法一致。
- **去掉幻听**：静音段常被识别成“谢谢观看”“字幕由…提供”之类，会被自动过滤。
- **录音不丢**：每段音频先存在手机上，转写成功才删除。断网时会在恢复后补上。

你还可以：

- 在 `TRANSCRIBE_VOCAB` 里写常说的人名和术语，用逗号分开。
- 手机别放太深的口袋，风大时把麦克风朝里。

## 精简导图

导图至少有 2 个节点时，底部会出现“精简导图”：合并重复的想法、把放错的节点挪到合适的分支、把长句缩成关键词。内容不会丢，被合并的原话会保留。不满意就点“撤销”。

## 锁屏录音

| 手机 | 怎么录 |
|---|---|
| Android（Chrome） | 点“开始录音”，然后锁屏。第一次请先录几分钟试试，结束时页面会告诉你有没有漏录 |
| iPhone | 网页录音时屏幕必须亮着，这是 iOS 的限制。要锁屏，就用“语音备忘录”录完，存到“文件”，再点“上传录音” |

## 语言

右上角的按钮切换界面的中文和英文。口述内容保持你说话用的语言，不会被翻译。

## 配置

| 变量 | 默认值 | 作用 |
|---|---|---|
| `OPENAI_API_KEY` | 无 | 必填 |
| `OPENAI_BASE_URL` | OpenAI 官方地址 | 用 ELM 时填 `https://elm.edina.ac.uk/api/v1` |
| `ACCESS_KEY` | 无 | 访问密钥，至少 16 个字符。没设时服务器只监听本机 |
| `HOST` | `127.0.0.1` | 部署时设为 `0.0.0.0`，这时必须有 `ACCESS_KEY` |
| `OPENAI_MODEL` | `gpt-5.6-sol` | 整理想法的模型 |
| `OPENAI_TRANSCRIBE_MODEL` | `gpt-transcribe` | 转写模型，接口没有时依次改用 `gpt-4o-transcribe`、`whisper-1` |
| `TRANSCRIBE_VOCAB` | 无 | 常用人名、术语，帮助识别 |

## 已知限制

- 字是一句一句出来的，不是一个字一个字地跳。
- 上传的单个音频文件不能超过 25 MB（语音备忘录约 25 分钟）。App 内录音分段上传，没有这个限制，最长 2.5 小时。
- 导图只存在手机浏览器里，换手机或清除网站数据会丢失。可以在“大纲”页复制备份。
- `app/index.html` 也是 claude.ai 版页面的源码，那个版本不能录音。
